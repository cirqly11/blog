# Technikkreis

Personal blog for Technikkreis — praxis statt hype. GitHub Pages serves it from the `main` branch at https://cirqly11.github.io/blog/.

The home page shows four topics: Smart Home, E-Auto / Wallbox, PV / Energie, and KI. A bubble turns active when a post lists that topic in `categories` or `tags`. Recognized values are `smart-home`, `e-auto` (or `wallbox`), `pv` (or `energie`, `photovoltaik`), and `ki`. Post URLs stay on the date path, so a topic does not move an entry.

Markdown images, figures, and inline graphics in a post are styled with the entry.
