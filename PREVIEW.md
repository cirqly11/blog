# Preview before merge

This pull request is a visual redesign. It stays open until Julian reviews it.

1. Review this PR (screenshots and the changed layouts).
2. Say merge to the Blog bot.
3. The bot merges. Do not merge it yourself unless that is what you mean to do.

Desktop screenshots are in `assets/preview/` (`home-desktop.png`, `about-desktop.png`, `post-desktop.png`). They are not published with the site.

After the merge, GitHub Pages rebuilds the site at https://cirqly11.github.io/blog/.
